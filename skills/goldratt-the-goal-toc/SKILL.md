# 目标：简单而有效的常识管理 / The Goal

作者：Eliyahu M. Goldratt（高德拉特）与 Jeff Cox（杰夫·科克斯）。基于用户提供的本地OCR文本，共40章。优先用本技能做逐章学习、概念自测与项目诊断。

## 调用规则

1. 任何具体问题先读对应章节；跨主题读最相关的2–3章，并查看术语表或方法库。
2. 逐章学习采用“解释一个判断→重构一个例子→提问检查理解→给一个练习”的节奏；等待用户作答再给反馈。
3. 原句、数值、故事细节、代码或争议观点必须用[原文读取工具](scripts/read_source.py)按章节行号核对。工具需要本机匹配的原始OCR；无法访问时明确说明不能核验。
4. 区分作者观点、书中引用/案例、本技能推演、今天的事实。OCR图像未读取，不能声称已核对图表或印刷页码。
5. 面对现实项目，以用户目标和现有证据开始；信息不足时标注假设，提出一个可验证的下一步。

## 核心框架

- **目标与运营衡量**：先问组织怎样赚钱，再以有效产出、存货、营运费检验局部改进；机器人效率和人员忙碌不自动构成经营成果。 [第5章](chapters/ch05.md)–[第8章](chapters/ch08.md)
- **依赖事件与统计波动**：健行队伍、火柴游戏说明串联流程的波动会积累延迟；仅靠平均能力规划无法保护交期。 [第13章](chapters/ch13.md)–[第15章](chapters/ch15.md)
- **制约与系统吞吐**：找出限制全局产出的因素，优先保护其时间；非制约资源应服从系统节奏。 [第18章](chapters/ch18.md)–[第26章](chapters/ch26.md)
- **持续改进五步**：识别、利用、协调、提升约束，随后重新识别；书末将物理约束延伸至政策和管理惯性。 [第36章](chapters/ch36.md)–[第40章](chapters/ch40.md)
- **财务口径冲突**：成本会计下的局部最优可能损害全局产出，需将决策与现金及订单结果对齐。 [第29章](chapters/ch29.md)–[第36章](chapters/ch36.md)
